# Horizon Summit 2027



## About the Project

Horizon Summit 2027 is a responsive conference website designed for a three-day technology event bringing together developers, designers, AI researchers, and technology professionals.

The website provides information about the conference, speakers, event schedule, ticket packages, and contact details.

## Features

- Responsive navigation menu
- Hero section with event information
- About the conference section
- Five featured speakers
- Event schedule
- Three ticket packages
- Contact form using FormSubmit
- Responsive footer
- Mobile-friendly design

## Technologies

- HTML5
- CSS3
- Git and GitHub

## Getting Started

1. Clone this repository:

```bash
git clone https://github.com/WaleedSK/conference-website.git
```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser or use the Live Server extension.
